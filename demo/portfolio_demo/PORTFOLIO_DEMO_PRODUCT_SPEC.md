# Portfolio Demo 产品说明书（Product Spec）

项目名称：**A股智能交易决策系统 V1.0｜Portfolio Demo**  
文档性质：**产品结构设计（只设计，不开发）**  
数据基准：`RESEARCH_BACKEND_GOLDEN_MASTER_2026-09-14`（只读）

---

## 1. 产品定位

> **将市场环境、板块状态、策略适配与个股信号，整合为一套可解释的交易决策辅助系统。**

| 是 | 不是 |
|---|---|
| A股研究与交易决策**辅助**系统 | ❌ 荐股系统 |
| 基于**真实历史数据**的研究产品 | ❌ 自动交易系统 |
| **可解释**的决策依据展示 | ❌ 收益承诺 / 收益保证 |
| **持续研究、验证、否定、优化**的策略产品 | ❌ 行情软件 / 选股器 |

一句话电梯陈述（首屏）：

> 用真实数据回答四个问题：现在是什么市场？该用哪类策略？今天有什么信号？为什么是它？

## 2. 目标用户与核心痛点

### 2.1 演示场景用户（第一优先级）

**招聘方 / 面试官**：第一次接触项目，需要在 3–5 分钟内判断候选人的产品设计、数据能力与工程落地能力。

### 2.2 真实产品用户画像

| 维度 | 描述 |
|---|---|
| 人群 | 具备基础投资经验的个人投资者 / 研究型交易者 |
| 场景 | 盘后研究、制定次日计划、复盘策略表现 |
| 痛点 1 | 信息碎片化：市场、板块、个股、策略各自为战，缺少统一决策链 |
| 痛点 2 | 策略与市场环境脱节：不知道当前环境适不适合某类策略 |
| 痛点 3 | 决策无依据：只有一个股票代码，没有“为什么” |
| 痛点 4 | 风险不透明：不知道最大风险在哪、退出条件是什么 |
| 痛点 5 | 策略不可验证：没有历史研究、没有边界、没有失败案例 |

## 3. 核心场景（User Stories）

| # | 场景 | 用户问题 | Demo 页面 |
|---|---|---|---|
| S1 | 盘后 10 秒判断市场 | “今天是什么市场？” | 首页 / 市场环境 |
| S2 | 判断策略适配 | “现在适合研究哪类策略？” | 市场环境 → 策略中心 |
| S3 | 查看今日候选 | “今天系统发现了什么？” | 今日信号 |
| S4 | 理解单个信号 | “为什么是这只股票？” | 个股详情 |
| S5 | 评估风险 | “最大风险是什么？什么时候退出？” | 个股详情（风险模块） |
| S6 | 验证策略可信度 | “这个策略历史上靠谱吗？边界在哪？” | 策略中心 → Strategy1 |
| S7 | 看到研究能力 | “策略是怎么被验证/否定/迭代的？” | 策略中心 → Strategy2 研究 |

## 4. 产品目标（验收标准）

1. **3–5 分钟理解**：招聘方按演示主线可完整理解 7 个问题（定位/需求/市场/策略/个股依据/风险/研究迭代）；
2. **6 个核心页面**：不做 17 页研发后台；导航不超过 6 项（+1 个详情页）；
3. **每页一个核心问题**：信息层级 = 事实 → 状态 → 影响 → 行动；
4. **真实数据**：全部来自正式 API；无假数据、无假信号、无假回测；
5. **诚实边界**：`PARTIAL_UNIVERSE`、`NOT_AVAILABLE`、`PARTIALLY_SUPPORTED`、`NOT_READY` 原样呈现；
6. **风险突出**：每页都有明确的风险/边界表达，且区分“统计合成曲线回撤”与“组合模拟回撤”；
7. **负结果不隐藏**：Strategy2 的负结果与未进入正式线的原因是核心叙事资产。

### ① 首页｜Dashboard

| 项目 | 内容 |

| 目标 | 10 秒内知道“这是什么产品” |
| 核心问题 | 这个产品解决什么问题？今天市场发生了什么？ |

### ④ 策略中心（核心页面）

**Strategy1｜正式验证线**

| 项目 | 内容 |
|---|---|
| 策略逻辑概览 | 隔日趋势 + 价格位置；连续两日收盘 > MA5；MA5 距离 3%–10%；20日压力距离 30%–50% |
| 交易约束 | T 日信号 → T+1 集合竞价条件成交 → 最早 T+2 退出；遵守 T+1 |
| 历史回测核心结果 | 6,049 笔 / 胜率 56.46% / 平均净收益 +1.379% / 盈亏比 1.505 |
| 风险指标 | 组合模拟最大回撤 −16.63%（基准假设）；统计合成曲线最大回撤 −62.529%（`STATISTICAL SYNTHETIC CURVE — NOT PORTFOLIO RISK`）；A/B/C 资金管理敏感性（研究性组合模拟，不构成最优仓位结论） |
| 当前适用环境 | Market Regime 分层历史证据（描述性） |
| 策略适用边界 | 未应用历史流通市值/ST 过滤；PARTIAL_UNIVERSE；不是实盘策略 |
| 数据 | `/api/v1/backtest/performance`、`/api/v1/strategies/strategy1/regime-performance`、`/api/v1/strategies/strategy1/portfolio-risk` |

**Strategy2｜关键价格地标研究（实验研究线）**

| 项目 | 内容 |
|---|---|
| 状态 | **Research Gate = `PARTIALLY_SUPPORTED`**（不是“没有策略2”） |
| 研究目标 | 价格回到历史关键止跌地标 L 附近后，是否存在可重复的研究现象与交易证据 |
| 研究过程 | L 定义（FROZEN）→ Revisit 事件研究 → 行为分类 → T 日可见特征 → 特征独立性 → 稳健性 → 候选条件收敛 → 原型回测 → 第二轮收益/交易稳健性 |
| 主要发现 | L 相对普通 1% 回调存在小幅优势；承接强度 HIGH 在部分退出方式下更好 |
| 支持证据 | 1,428 Revisit / 2,535 Control / 19,805 笔交易级原型；LOW-MID-HIGH；Portfolio Risk（HIGH/TIME_20 −23.15%） |
| **负结果（必须展示）** | 跨时间不稳定（2020–2021 反向）、跨市场不稳定（SH_MAIN 反向）、退出方式敏感（REBOUND 反向）、MID 非单调；`EXIT-SENSITIVE` |
| 为什么未进入正式线 | 稳定性未确认 + 无稳定 edge + 项目纪律（不满足上线标准不创建 V1.1） |
| 下一步如何优化 | 数据治理（复权/ST/停牌/流通市值）→ 更大样本验证；任何下一步需人工授权 |
| 数据 | `/api/v1/strategies/strategy2/landmark-research`、`/api/v1/strategies/strategy2/landmark-evidence` |

| 项目 | 内容 |
|---|---|
| 目标 | 展示“市场 → 板块 → 策略 → 个股条件 → 信号”的完整链路 |
| 核心问题 | 为什么这个信号产生？ |
| 模块 1｜链路说明 | 一条可视化链路（市场环境 → 板块环境 → 策略适配 → 股票筛选 → 交易条件 → 信号），标注每步数据来源与当前状态 |
| 模块 2｜候选列表 | 少量候选（示例数据日 2026-08-25 共 3 条：000779 甘咨询 / 002047 宝鹰股份 / 605286 同力天启） |
| 模块 3｜每条信号的关键字段 | 股票、所属板块（`NOT_AVAILABLE` 时如实标注）、当前策略、信号状态、触发原因、买入条件（计划买入价 = MA5×1.03）、T+1 条件（开盘价 ≤ 计划价才成交）、风险提示 |

### ⑥ 个股详情

| 项目 | 内容 |
|---|---|
| 目标 | 回答“为什么是这只股票？风险在哪？” |
| 核心问题 | 可解释的决策依据，而不是买/卖结论 |
| 模块 1｜个股基本状态 | 代码/名称、P1 RAW 行情状态、最近信号、所属板块（如实标注 NOT_AVAILABLE）、市场环境背景 |
| 模块 2｜信号解释（条件清单） | 趋势条件 ✓ / MA5 距离条件 ✓ / 20日压力距离条件 ✓ / 竞价成交条件（待 T+1 确认）/ 策略与市场环境状态 |
| 模块 3｜风险 | 最大单笔亏损（−5.16% 止损口径）、Exit Engine 三类退出优先级、T+1/T+2 约束、计划价 ≠ 成交价提示 |
| 模块 4｜历史验证 | 该策略的真实历史结果（全量 + 该股历史交易记录/退出原因） |

### ⑦ 策略研究 / 产品迭代（并入策略中心）

保留独立入口（策略中心内「Strategy2 研究」），展示：

```text
研究假设 → 数据验证 → 回测 → 发现问题 → Research Gate → 是否进入正式策略
```

核心表达：**策略不是一次写完的，而是持续研究、验证、否定、优化。** Strategy2 是最佳案例。

## 6. 产品设计原则

1. **每页一个问题**：页面标题即用户问题；
2. **事实 → 状态 → 影响 → 行动**：所有指标必须解释“所以呢”；
3. **KPI 少而重要**：每页不超过 5 个核心 KPI；
4. **风险与边界前置**：风险不藏在折叠区；
5. **诚实优先**：负结果、数据缺口、未实现能力如实标注；
6. **不做自动决策**：所有输出都是“研究证据/决策依据”，不是买卖指令；
7. **不制造 AI 推荐感**：不出现“AI 推荐”“智能选股”等误导表达。

## 7. 视觉方向

* 风格：**专业金融投研产品 + 现代 AI 产品**（非金融后台风）；
* 布局：卡片化、层级清楚、留白充足；每屏一个主信息；
* 图表：简洁（趋势线、状态卡、少量柱状图），避免满屏表格；
* 状态：颜色语义统一（绿=正常/正向，橙=注意/研究性，红=风险/负结果，灰=未实现）；
* 徽章体系：`真实数据` / `研究性` / `NOT_AVAILABLE` / `PARTIALLY_SUPPORTED` / `NOT PORTFOLIO RISK`；
* 首屏原则：招聘方不滚动即可看到“产品是什么 + 今日市场 + 今日信号 + 研究可信度”。

## 9. 非目标（明确不做）

* 不接入券商、不下单、不自动交易；
* 不做实时行情/Level-2/资金流（数据源未验证）；
* 不做个股综合评分 / 候选排序 / expected return（无冻结定义）；
* 不做参数优化 / 最优仓位 / 最优退出；
* 不新增策略（Strategy3～6 需独立立项授权）；
* 不复制研发后台 17 个页面。
